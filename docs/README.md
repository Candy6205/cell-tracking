# docs/ — the project documents

**These files are the master copy.** Every session edits them here, in the
repository. The Claude Project of the same name holds an older transcription of
the same material and is no longer authoritative — if the two disagree, this
folder wins.

| file | what it is |
|---|---|
| `strategy.md` | where we are, what to do next, and what we have decided NOT to do |
| `progress.md` | the experiment log: every measurement, every result, every trap |
| `competition-brief.md` | task, data format, the exact metric rules |
| `engineering-rules.md` | 11 conventions every script follows, each from something that broke |
| `holdout-split.md` | which datasets the public weights were trained on — mostly superseded |
| `public-solutions-recon.md` | what the public leaderboard actually contains, read from the forum |
| `kaggle-toolchain.md` | how to actually run things: CLI pushes, connector reads, and the traps |

Read order for a cold start: `strategy.md`, then `public-solutions-recon.md`,
then `progress.md`.
